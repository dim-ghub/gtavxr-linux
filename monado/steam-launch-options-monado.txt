# Test GTAVXR against Monado's simulated headset (no VR hardware needed).
# 1. ./start-monado.sh (and once: pos-tracked-layer/install.sh)     2. paste the line below into GTA V's Launch Options
# 3. launch GTA V from Steam, leave Suite → Settings → Headset on Automatic, press Play
#
# XR_RUNTIME_JSON         Linux-side runtime: host Monado, as seen from inside Steam's container
# PRESSURE_VESSEL_...     lets the container reach monado-service's IPC socket
# VR_OVERRIDE             Proton only sets up wineopenxr after its OpenVR client initializes;
#                         xrizer (OpenVR on top of OpenXR) lets that happen without SteamVR.
#                         Only affects this launch, not ~/.config/openvr/openvrpaths.vrpath.
# GTAVXR_LINUX_POS_TRACKED turns on pos-tracked-layer (install it once with
#                         pos-tracked-layer/install.sh): Monado's simulated HMD never reports
#                         POSITION_TRACKED, and GTAVXR won't render a frame without it.
# XR_LOADER_DEBUG / PROTON_LOG   loader + Proton diagnostics in ~/steam-271590.log

PROTON_LOG=1 XR_LOADER_DEBUG=all GTAVXR_LINUX_POS_TRACKED=1 VR_OVERRIDE=/opt/xrizer XR_RUNTIME_JSON=/home/dim/Projects/gtavxr-linux/monado/openxr_monado_container.json PRESSURE_VESSEL_FILESYSTEMS_RW=/run/user/1000/monado_comp_ipc bash -c 'exec "${@/PlayGTAV.exe/GTAVXR.exe}"' -- %command%
